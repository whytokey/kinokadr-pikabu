# КиноКадр — порт на Pikabu Games

Игра «Угадай фильм по отрывку», перенесённая с Яндекс Игр на платформу
**games.pikabu.ru**. Вся логика, вёрстка и игровые механики сохранены без изменений —
переписана только платформенная обвязка (SDK, реклама, покупки, сохранения).

## Что изменилось

| Было (Яндекс Игры) | Стало (Pikabu Games) |
| --- | --- |
| `YaGames.init()` | `PkbSDK.init()` |
| `YaGames.features.LoadingAPI.ready()` | `sdk.gameStarted()` |
| `GameplayAPI.start() / stop()` | удалено (на Pikabu нет аналога) |
| `adv.showBannerAdv()` — липкий баннер | `ads.preloader` — баннер на экране загрузки (только мобильные, до `gameStarted()`) |
| `adv.showFullscreenAdv()` | `ads.fullscreen.show()` → `{ rendered }` |
| `adv.showRewardedVideo()` | `ads.rewarded.show()` → `{ rendered, reward }` |
| `payments.getCatalog()` | `store.getProducts()` |
| `payments.purchase()` / `consumePurchase()` | `store.purchase()` / `store.consumePurchase()` |
| `player.getData()` / `setData()` | `storage.get()` / `storage.set()` + `storage.flush()` |
| `auth.openAuthDialog()` | `auth.openAuthDialog()` |
| `leaderboards.setScore()` / `getEntries()` | **удалено** — на Pikabu нет таблицы лидеров |
| `shortcut.showPrompt()` | **удалено** — на Pikabu нет ярлыков |
| `feedback.requestReview()` | **удалено** — на Pikabu нет отзывов |
| `environment.i18n.lang` | `navigator.language` |
| цены `YAN` | цены `₽` из каталога студии |

### Убрано из интерфейса

- **«Рейтинг»** — на Pikabu SDK нет таблицы лидеров, пункт меню и соответствующее
  модальное окно удалены.
- **«Ярлык»** — на Pikabu нет API для добавления ярлыка на домашний экран.
- **Запрос отзыва** — на Pikabu нет аналога `feedback.requestReview()`.

### Добавлено

- **Вход в аккаунт** в настройках (`Опции → Аккаунт`). На Pikabu облачные сохранения
  привязаны к аккаунту, поэтому вход нужен, чтобы прогресс переносился между
  устройствами. Сам вход доступен и из интерфейса платформы.
- Обработка события `storageSaveError`: при конфликте версий сохранения игроку
  показывается подсказка перезагрузить игру.
- Кнопка покупки «Войти» теперь всегда доступна (на Яндексе она жила внутри
  окна рейтинга).

## Структура

```
kinokadr-pikabu/
├── index.html          — разметка, подключение SDK Pikabu
├── style.css           — стили (без изменений, кроме мелких правок)
├── game.js             — игровая логика + обвязка над Pikabu SDK
├── pikabu-sdk.js       — фасад над PkbSDK (загрузка скрипта, реклама, магазин, storage)
├── player.js           — HTML5-плеер отрывков (без изменений)
├── clips.js            — список видео (без изменений)
└── videos/             — mp4-отрывки (нужно перенести из сборки Яндекс Игр)
```

## Что нужно сделать перед публикацией

### 1. Перенести видео

Папка `videos/` с mp4-файлами (`videos/<id>.mp4`, 60 штук) в репозиторий не вошла —
её нужно скопировать из исходной сборки. Пути в `clips.js` относительные, поэтому
сборка будет работать из любой подпапки GitHub Pages.

> GitHub Pages: лимит на один файл — 100 МБ, на репозиторий — до 2 ГБ. Если отрывки
> не влезают, часть роликов стоит сжать (`ffmpeg -i in.mp4 -crf 30 -preset slow -vf scale=640:-2 out.mp4`)
> или перевести в VP9/WebM.

### 2. Завести товары в Студии Pikabu Игр

Откройте [games.pikabu.ru/studio](https://games.pikabu.ru/studio) → ваша игра →
**Товары**. Создайте товары с такими же ID, как были на Яндексе — тогда игра
подхватит их автоматически, код менять не нужно:

| ID товара | Что даёт | Цена (резервная в коде) |
| --- | --- | --- |
| `coins_small` | 300 монет | 49 ₽ |
| `coins_medium` | 1000 монет | 129 ₽ |
| `coins_large` | 3000 монет | 299 ₽ |
| `no_ads` | убирает рекламу (прелоадер + фуллскрин) | 199 ₽ |
| `vip` | все категории + 2000 монет + без рекламы | 399 ₽ |

Резервные цены в `CONFIG.products` — только фолбэк на случай, пока товар не заведён
в студии. Актуальная цена всегда берётся из `sdk.store.getProducts()`
(`product.formattedPrice`). Чтобы поменять ID товара — правьте ключи в
`CONFIG.products` в `game.js`.

### 3. Задеплоить на GitHub Pages

```bash
cd kinokadr-pikabu
git init
git add .
git commit -m "КиноКадр для Pikabu Games"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch →
branch `main`, папка `/ (root)`**. Через 1–2 минуты игра будет доступна по адресу
`https://<user>.github.io/<repo>/`.

Все пути в проекте относительные (`style.css`, `clips.js`, `videos/...`), поэтому
игра корректно работает из подпапки репозитория — отдельный `base` или сборщик не
нужны. Файл `.nojekyll` уже добавлен, чтобы Jekyll не вырезал файлы.

В Студии Pikabu Игр укажите адрес страницы с игрой (URL GitHub Pages) и загрузите
сборку, если потребуется архив.

## Проверка требований Pikabu

- [x] SDK подключён (`https://games.pikabu.ru/sdk/sdk.js`), вызывается `sdk.gameStarted()`
- [x] Автопауза: при уходе во вкладку (`visibilitychange`), при показе рекламы,
      при окне авторизации и при форме оплаты
- [x] Фоновое аудио глушится на паузе
- [x] Облачные сохранения обязательны — реализованы через `sdk.storage`
- [x] Работоспособность с блокировщиком рекламы — награда выдаётся только по
      флагу `reward` из ответа SDK
- [x] Игра размещена на собственном сервере (GitHub Pages)
- [x] Русский язык по умолчанию

## Особенности реализации

**Реклама.** Прелоадер показывается на экране загрузки — только на мобильных и
только до вызова `sdk.gameStarted()`, поэтому порядок в `boot()` важен: сначала
`SDK.showPreloader()`, затем `SDK.ready()`. Фуллскрин — между уровнями с
кулдауном 60 секунд. Rewarded — за 50 монет, за удвоение награды, за воскрешение
и за x2 к ежедневному бонусу.

**Покупки.** Покупка подтверждается начислением товара, затем расходуемый товар
подтверждается вызовом `consumePurchase()`. Необработанные покупки
восстанавливаются при следующем запуске через `store.getPurchases()`.

> ⚠️ Валидация покупок на бэкенде (`purchase.getSignedData()`) не подключена:
> сборка статическая, сервера нет. Для продакшена с реальными платежами стоит
> добавить бэкенд, который проверяет подпись и начисляет товар — так требует
> документация Pikabu для расходуемых товаров. До этого момента начисление
> происходит на клиенте (как было на Яндекс Играх).

**Локальный режим.** Если SDK Pikabu недоступен (например, при локальной отладке
или если CDN недоступен), игра не падает: включается mock-режим, реклама
заменяется тестовой заглушкой, а покупки начисляются без оплаты. Так удобно
проверять игровые механики до модерации.

> Нюанс: SDK Pikabu handshake'ится с родительским фреймом платформы. Если страница
> открыта сама по себе, ответа не будет — игра ждёт 3 секунды и уходит в mock-режим.
> На самой платформе handshake проходит мгновенно.

**Защита от бесконечного цикла.** Вне платформы «родитель» — это сама страница, и
наивный SDK начал бы постить себе бесконечно. `pikabu-sdk.js` гасит повторные
самопосты `pkbsdk:ready`, оставляя первый (он нужен платформе), и ограничивает
`PkbSDK.init()` таймаутом.

**Определение языка.** Pikabu SDK не отдаёт язык окружения, поэтому язык
определяется по `navigator.language` (русский/белорусский/казахский/украинский/
узбекский → русский, остальные → английский) и переключается в настройках.

## Проверка локально

```bash
cd kinokadr-pikabu
python3 -m http.server 8123
# открыть http://127.0.0.1:8123
```

Без платформы игра запустится в mock-режиме (тестовая реклама вместо настоящей).
