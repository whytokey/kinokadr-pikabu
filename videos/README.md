# Отрывки фильмов

В эту папку кладутся mp4-файлы отрывков. Имена и пути берутся из `clips.js`:

```
videos/titanic.mp4
videos/matrix.mp4
videos/interstellar.mp4
...
```

Список всех 60 файлов — в `../clips.js` (ключ объекта `window.KINOKADR_CLIPS`
равен id фильма, поле `src` — путь к файлу).

Папка пустая в этом билде — файлы нужно перенести из сборки Яндекс Игр.
Пути относительные, поэтому видео корректно отдаётся с любого подпути GitHub Pages.
